Week 2: Logistics Data Collection & Preprocessing

Overview

This project focuses on data collection, cleaning, and preprocessing for logistics analytics. A publicly available supply-chain dataset is used as a reference to simulate a practical data preprocessing workflow in Python.

Objectives

- Collect and understand logistics-related data.
- Identify common data quality issues.
- Handle missing values, duplicates, outliers, and inconsistent data.
- Apply appropriate preprocessing and normalization techniques.
- Prepare a reliable dataset for further analysis.

Methodology

The preprocessing workflow follows:

"Data Collection → Data Profiling → Data Cleaning → Missing Value Handling → Outlier Detection → Feature Engineering → Scaling → Validation"

Each step is documented with its purpose and impact on subsequent logistics analysis.

Key Techniques

- Pandas & NumPy for data inspection and cleaning.
- Missing Value Handling using context-based imputation.
- Duplicate Detection to prevent double counting.
- Outlier Detection using IQR and business rules.
- Date & Data Type Processing for reliable calculations.
- Categorical Standardization for consistent analysis.
- Scaling/Normalization when required by the analytical method.

Dataset

A public DataCo Smart Supply Chain dataset is used as the reference dataset. It contains logistics-related information such as orders, shipping, products, customers, sales, and delivery data.

«Dataset is used for academic and preprocessing demonstration purposes.»

Technologies

Python | Pandas | NumPy | Scikit-learn

Key Takeaway

High-quality data is essential for reliable logistics analytics and decision-making. A structured preprocessing pipeline helps ensure that subsequent analysis and models are based on consistent, accurate, and meaningful data.
